# Khrung Thep – Thai Restaurant & Matcha Cafe: online ordering demo

A demo of the Khrung Thep WooCommerce ordering site (208 Sports Rd, Westlands, Nairobi) that runs entirely in the browser with WordPress Playground.

- Ordering site: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/khrung-thep-demo/main/blueprint.json
- Store admin (menu, prices, orders, bookings): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/khrung-thep-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so test orders are not kept.
